# UAH-Motorsport
##  AIRs Logic, Precharge and Discharge Management

En la PDU añado toda la gestión de la lógica de los AIRs y la precarga y descarga, ya que sino realizar solo el mandar mensajes por CAN me parece poco para el TFG.

## Implemented Features

- Control de la secuencia de apertura y cierre de los AIRs  
- Gestión de la precarga para limitar de forma segura la corriente de irrupción  
- Control de la descarga para reducir de forma segura la tensión tras la desconexión  
- Implementación de lógica basada en estados para garantizar una operación segura  
- Comprobaciones básicas de seguridad y gestión de fallos   Basic safety checks and fault handling
